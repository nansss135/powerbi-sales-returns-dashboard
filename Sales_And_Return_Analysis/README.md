## Sales & Returns Performance Dashboard

### Overview

This project presents a comprehensive **Sales and Returns Analysis Dashboard** built using **Power BI and DAX**. The dashboard provides insights into sales performance, profitability, customer behavior, and return trends across different regions, segments, and time periods.

The design focuses on **interactivity, clarity, and business insights**, making it suitable for decision-making and performance evaluation.

---

## Key Performance Indicators (KPIs)

The dashboard includes the following KPI cards:

* Total Sales: 848.40K
* Total Profit: 162.17K
* Total Cost: 686K
* High Value Sales: 558.01K
* Average Sales per Transaction: 848.40
* Unique Customers: 100
* Return Rate: 0.10

These KPIs provide a quick snapshot of overall business performance.

---

## Filters (Slicers)

Interactive slicers are used to filter the dashboard dynamically:

* Month Name Slicer: Allows filtering data by specific months
* Region Name Slicer: Filters data by regions (Central, East, North, South, West)

All visuals update automatically based on selected filters.

---

## Visualizations Used

### 1. Gauge Chart – High Value Sales Performance

* Displays High Value Sales vs Target
* Helps track performance against a defined benchmark
* Dynamically updates with slicers

---

### 2. Donut Chart – Total Sales by Segment

* Shows distribution of sales across:

  * Retail
  * Corporate
  * SMB
* Helps identify the highest contributing segment

---

### 3. Funnel Chart – Total Returns by Segment

* Displays number of returns across customer segments
* Highlights where return rates are highest

---

### 4. Line Chart – Total Profit by Month

* Shows monthly profit trends
* Helps identify peak and low-performing periods

---

### 5. Decomposition Tree – Sales Breakdown Analysis

* Breaks down Total Sales into:

  * Segment
  * Category
  * Region
* Helps identify key contributors to sales performance
